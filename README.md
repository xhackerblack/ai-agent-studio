# استوديو وكلاء الذكاء الاصطناعي — AI Agent Studio

منصة كاملة لبناء وكلاء ذكاء اصطناعي مخصصين، وتدريبهم **بملف واحد**، وإدارتهم من لوحة تحكم — كل ذلك من الهاتف. تعمل بالكامل على **Cloudflare** (الطبقة المجانية: Workers AI + KV)، ولا تحتاج Vercel.

- 🤖 **منشئ وكلاء**: إنشاء يدوي كامل أو "تخصيص سريع" — صف ما تريد بجملة واحدة فيُولَّد الوكيل (الاسم، الشخصية، تعليمات النظام، الأدوات).
- 💬 **محادثة متدفقة** (Streaming) مع استخدام تلقائي للأدوات، وشارات تُظهر أي أداة استُخدمت.
- 📄 **تدريب بملف واحد**: ارفع TXT/MD/CSV/JSON/HTML (وPDF تجريبياً) → استخراج نص → تقسيم → Embeddings → قاعدة معرفة خاصة بالوكيل (RAG) — دون أي تدخل منك.
- 🧠 **ذاكرة دائمة + تعلّم ذاتي**: بعد كل محادثة يستخلص الوكيل الحقائق والدروس والفجوات المعرفية **بنفسه**، ويعرضها في **سجل تعلّم مرئي** (Timeline).
- 🧰 **أدوات كثيرة**: آلة حاسبة، تاريخ/وقت، تحويل عملات، جلب روابط، Webhook/API خارجي، تذكيرات — مع إمكانية إضافة أدوات مخصصة دون كود.
- 🎨 **توليد صور بالذكاء الاصطناعي** (FLUX.1): تبويب "استوديو الصور" — صف بالإنجليزية واختر الأسلوب (واقعي، كرتوني، أنمي، زيتي…) واحفظ/حمّل النتيجة. والوكلاء أيضاً يستطيعون الرسم: فعّل أداة "توليد صورة" لأي وكيل ثم اطلب منه في المحادثة.
- 🧠 **عقل الوكيل الحي**: تبويب يعرض شبكة معرفية تفاعلية (canvas فيزيائي) — الذكريات، الدروس، ملفات التدريب، الأدوات، المهارات، وأحداث التعلّم — كلها بيانات حقيقية مباشرة، مع إحصائيات حية وتحديث تلقائي.
- 🧩 **مكتبة مهارات**: حزم تعليمات جاهزة (تسويق، برمجة، كتابة…) تُدمج في أي وكيل بنقرة، مع إمكانية إنشاء مهارات مخصصة.
- 🔄 **تعلّم ذاتي تلقائي**: فعّله لأي وكيل فيتعلم من كل محادثة وحده في الخلفية (يظهر في سجل التعلّم).
- 📊 **لوحة تحكم**: إحصائيات، رسم نشاط ٧ أيام، سجل التعلّم، ملفات التدريب، الأدوات، التذكيرات، عدّاد الحصة اليومية.
- 📱 **PWA**: يُثبَّت على الأندرويد كتطبيق بملء الشاشة + **مشروع APK جاهز** (مجلد `android/` + GitHub Actions يبني ملف APK تلقائياً).
- 🔬 **البحث المعمق**: زر «بحث معمق» — يبحث الوكيل في قاعدة معرفته أولاً ثم الويب، ويلخّص ويحلّل، ويحفظ الدروس في عقله — مع **خريطة بحث حيّة** تعرض كل مرحلة ومصدر، وسجل بحوث في لوحة التحكم.
- 🛰️ **الباحث المستقل**: فعّله لأي وكيل فيبحث في الويب **تلقائياً كل ٣ ساعات** (مواضيعك أو فجواته المعرفية) ويحفظ الحقائق الجديدة في ذاكرته — مع **شريط إخباري حي 📡** في لوحة التحكم يعرض نشاط الوكلاء لحظة بلحظة، ومفتاح إيقاف/تشغيل وتعديل الفترة من الإعدادات.
- 🔬 **التفكير العميق**: فعّله لأي وكيل — يحلّل السؤال خطوة بخطوة (صندوق تفكير مرئي قابل للطي)، مع مستويات جهد (سريع/متوازن/عميق) ونقد ذاتي للإجابة قبل إرسالها + تقييم جودة ذاتي يظهر في صفحة العقل.
- 🔍 **بحث الويب**: أداة جديدة للمعلومات الحديثة (أسعار، أخبار)، والوكيل ينفّذ **سلاسل أدوات** متتالية تلقائياً.
- 💾 **النسخ الاحتياطي**: تنزيل/استعادة كل شيء بملف واحد، وتصدير/استيراد عقل أي وكيل.
- 🕘 **سجل إصدارات** لكل وكيل مع التراجع، 👤 **ملف شخصية أعمق** (خبرة/أسلوب/تجنّب)، ↗️ **مشاركة المحادثات**، 🔗 **معاينة الروابط**، 🔔 **تنبيهات التذكيرات**.

> ملاحظة معمارية: "العقل" يعمل بمحرك LLM (ضروري للاستدلال — الافتراضي Llama 3.1 8B fp8-fast المجاني ضمن الحصة)، بينما **التعلّم والذاكرة والتحسين ذاتية** وتعمل في الخلفية دون تدخلك.

## التشغيل والنشر (5 خطوات من الهاتف أو الحاسوب)

1. **أنشئ KV namespace**: من لوحة Cloudflare ← Workers & Pages ← KV ← Create namespace باسم `studio-kv`، ثم انسخ الـ ID.
2. ضع الـ ID في `wrangler.jsonc` مكان `STUDIO_KV_ID` (أو نفّذ: `npx wrangler kv namespace create studio-kv` وحدّث الملف).
3. ارفع المشروع على GitHub (كل الملفات مع الحفاظ على البنية).
4. في Cloudflare ← Workers & Pages ← Create ← **Import a repository** ← اختر المستودع ← أمر النشر `npx wrangler deploy`.
5. **(إلزامي) أضف `APP_PASSWORD` كـ Secret** — بدونه يرفض التطبيق كل مسارات `/api` برسالة 503. من الهاتف: Workers & Pages ← `ai-agent-studio` ← Settings ← Variables and Secrets ← Add secret ← الاسم `APP_PASSWORD` ← أدخل كلمة مرور قوية ← Save ← ثم Deployments ← أحدث نشر ← Retry deployment.

تحقق: افتح `https://<your-app>.workers.dev/api/config` — يجب أن ترى `"auth":{"required":true,"configured":true}`.

## الأسرار (Secrets)

| السر | إلزامي | الوصف |
|---|---|---|
| `APP_PASSWORD` | نعم | كلمة مرور التطبيق — الجلسة موقّعة بـ HMAC في كوكي HttpOnly + Secure + SameSite=Strict. لا تُخزَّن في localStorage أبداً |
| `INTERNAL_TOKEN` | لا | سر داخلي منفصل تُستثنى به مسارات الكرون/المهام الداخلية من جلسة الكوكي (ترويسة `x-internal-token`) |

أوامر wrangler:
```bash
wrangler secret put APP_PASSWORD
wrangler secret put INTERNAL_TOKEN   # اختياري
```

## 🛡️ الأمان وحارس الحصة (المرحلة 1)

- **بوابة إلزامية**: كل `/api` (عدا `/api/config` و`/api/login` و`/api/session` و`/api/images/*`) يتطلب جلسة صالحة، وإلا 401 مع شاشة دخول تظهر مرة واحدة.
- **حد محاولات الدخول**: 5 محاولات فاشلة من نفس الـ IP ← حظر 15 دقيقة (Cache API). للحماية الأقوى فعّل **Rate Limiting** من لوحة Cloudflare ← Security ← Rate limiting rules على المسار `/api/login`.
- **حارس الحصة**: كل استدعاء ذكاء اصطناعي يُقدَّر بالخلايا العصبية (حسب النموذج والتوكنز — الرقم **تقديري**) ويُجمَّع يومياً. السقف الافتراضي **8,000** وقابل للتعديل من الإعدادات.
  - عند **70%**: تتوقف المهام الخلفية تلقائياً (الباحث المستقل، التعلّم الذاتي) — وتظهر حالة ⏸️ في الإعدادات.
  - عند **100%**: المحادثة تتحول لأرخص نموذج (Llama 3.2 3B) مع تنبيه، وتوليد الصور يتوقف برسالة واضحة.
- **ميزانية KV**: العدّادات تُجمَّع في الذاكرة وتُفرَّغ دورياً عبر `waitUntil` (دقة تقريبية مقبولة)؛ فشل `put` (مثل تجاوز حد الكتابة اليومي) يُلتقط ويُسجَّل ويُكمل الطلب دون انهيار. عدّاد كتابات KV اليومية ظاهر في الإعدادات مع تنبيه عند 800/1000.
- **Cache API** (وليس KV) لنتائج البحث (30 دقيقة) والصفحات المجلوبة (6 ساعات).
- **الباحث المستقل**: افتراضياً كل **3 ساعات** (كان 30 دقيقة)، مع مفتاح تشغيل/إيقاف وتعديل الفترة (3/6/12/24) من الإعدادات ← 🛡️ الأمان والحصة.

## بناء ملف APK (اختياري)

1. بعد نشر الخادم، انسخ رابطه الكامل (https://…).
2. في GitHub: افتح المستودع ← Settings ← Secrets and variables ← **Actions** ← Variables ← أنشئ متغيراً باسم `APP_URL` قيمته رابط الخادم.
3. ادفع أي تعديل في مجلد `android/` (أو شغّل الـ workflow يدوياً من تبويب Actions ← Build debug APK ← Run workflow).
4. بعد انتهاء البناء، حمّل ملف `ai-agent-studio-debug` من الـ Artifacts وثبّته على هاتفك (اسمح بـ "مصادر غير معروفة" — توقيع Debug مخصص للتجربة الشخصية).

> الـ APK **غلاف WebView**: يفتح تطبيقك من الخادم بملء الشاشة. الذكاء الاصطناعي يعمل على الخادم — لا يمكن تشغيل النماذج داخل الهاتف وحده.

## التكلفة (طبقة Cloudflare المجانية)

- الحصة: **١٠٬٠٠٠ خلية عصبية/يوم** تُصفَّر عند ٠٠:٠٠ UTC.
- محادثة نموذجية (Llama 3.1 8B fp8-fast): بضع خلايا فقط.
- تدريب ملف متوسط: عشرات الخلايا.
- عدّاد الحصة يظهر أعلى التطبيق، وعند النفاد تتوقف التوليدات برسالة عربية واضحة.
